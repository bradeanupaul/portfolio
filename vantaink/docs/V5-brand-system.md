# V5 · Brand system (cut-line monogram)

## Concept
**VANTA / cut-line monogram**: a stylized **V** from two asymmetrical heavy strokes interrupted by a vermilion diagonal incision. References precision and cut, not needles or skulls.

## Files
| File | Role |
|---|---|
| `public/brand/vanta-symbol.svg` | Isolated cut-line V |
| `public/brand/vanta-wordmark.svg` | Constructed letterforms VANTA INK |
| `public/brand/vanta-lockup-horizontal.svg` | Symbol + wordmark (navbar/footer) |
| `public/brand/vanta-lockup-stacked.svg` | Stacked lockup |
| `public/brand/vanta-wordmark-light.svg` / `-dark.svg` | Tone variants |
| `public/brand/vanta-wordmark-white.png` | Raster navbar fallback |
| `public/brand/favicon.svg` + `src/app/icon.svg` | Favicon |

All letterforms are path geometry (not live HTML text). Accent vermilion `#FF5538` on the cut.
